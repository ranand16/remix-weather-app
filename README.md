# Weather Widget

This is a simple weather widget I built in Remix. It is built with Remix and Tailwind CSS and utilizes the Weather API.

## Technologies

-   [Remix](https://remix.run/)
-   [Tailwind CSS (widget template)](https://tailwindcss.com/)
-   [Weather API](https://www.weatherapi.com/)

## Initialize your app

-   Create a copy of .env.example file and rename it to .env.
-   Create a database(I used mongo atlas). Paste the DATABASE_URL in the .env file.
-   Go to https://www.weatherapi.com/ and add your WEATHER_API_KEY in the .env file.
-   SESSION_SECRET in .env could be anything.
